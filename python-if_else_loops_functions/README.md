This project contains Python exercises for conditionals, loops, ASCII character handling, reusable functions, and beginner algorithmic problems.

---

## Objective

To strengthen control flow and function skills by learning:

- Conditional statements
- Loops and ranges
- Number formatting
- ASCII conversion with `ord()` and `chr()`
- Function definitions and return values
- String transformations
- Basic algorithm design

---

## Topics Covered

### Conditions

- Positive, negative, and zero checks
- Last digit evaluation
- Branching with `if`, `elif`, and `else`

### Loops and Formatting

- Alphabet printing
- Filtering characters
- Decimal and hexadecimal formatting
- Number combinations

### Functions

- Lowercase checks
- Uppercase conversion
- Last digit extraction
- Addition and power calculations
- FizzBuzz

### Advanced Practice

- Reverse alphabet printing
- Character removal by index

---

## Requirements

- Python 3.x
- `pycodestyle`
- Scripts should be executable where required
- Function files should be importable by the provided main files

## Files

| File | Description |

| `3-print_alphabt.py` | Prints the alphabet excluding selected letters |

| `8-uppercase.py` | Prints a string in uppercase |
| `9-print_last_digit.py` | Prints the last digit of a number |

| `100-print_tebahpla.py` | Prints the alphabet in reverse with alternating case |
