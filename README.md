# Python Fundamentals - AI Academy (DLH)

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

This repository contains my Python fundamentals and higher-level programming exercises for the **AI Academy course at DLH**. It demonstrates hands-on practice across syntax, control flow, imports, data structures, exception handling, file I/O, serialization, and object-oriented programming.

---

## Objective

To build strong Python programming foundations by learning:

- Output formatting and string manipulation
- Control flow, loops, and functions
- Modules, imports, and command-line arguments
- Lists, tuples, sets, and dictionaries
- Exception handling and safe execution patterns
- File input/output and JSON handling
- Serialization with JSON, Pickle, CSV, and XML
- Object-oriented programming with classes and methods
- Magic methods, class methods, and static methods
- Algorithmic problem solving

---

## Topics Covered

### Python Basics

- Printing output
- Working with integers and floats
- String formatting
- String slicing and concatenation
- Python style constraints

### Control Flow and Functions

- Conditional statements
- Loops and ranges
- ASCII character handling
- Reusable functions
- FizzBuzz and small algorithms

### Modules and Arguments

- Importing functions and variables
- Using external modules
- `if __name__ == "__main__"`
- Command-line arguments with `sys.argv`
- Module discovery with `dir()`

### Data Structures

- Lists and tuples
- Sets and dictionaries
- Matrix traversal
- Functional tools such as `map()` and `lambda`
- Roman numeral conversion and weighted averages

### Robust Python Programs

- Exception handling
- Raising exceptions
- Printing errors to `stderr`
- Safe function execution

### Files, Serialization, and OOP

- Reading and writing files
- JSON serialization and deserialization
- Pickle, CSV, and XML workflows
- Classes, private attributes, and properties
- Object representation and comparison
- Linked lists and the N queens problem

## Requirements

- Ubuntu 20.04 LTS
- Python 3.x
- `pycodestyle`
- All Python files should be executable where required
- Python scripts should begin with `#!/usr/bin/python3` or `#!/usr/bin/env python3` based on task requirements
- Modules, classes, and functions should be documented where required

---

## Usage

Run a Python script:

```bash
python3 python-hello_world/2-print.py
```

Run a function task with its main file:

```bash
python3 python-data_structures/0-main.py
```

Run an object-oriented task:

```bash
python3 python-classes/6-main.py
```
